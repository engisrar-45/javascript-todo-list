# JavaScript Todo List

A responsive and interactive Todo List web application built using **HTML, CSS, and JavaScript**. This project allows users to easily create, manage, edit, complete, and delete tasks through a clean and user-friendly interface.

## Features

- Add new tasks to the Todo List
- Mark tasks as completed
- Edit existing tasks
- Delete tasks
- Store tasks using **Local Storage**
- Tasks remain saved even after refreshing the page
- Responsive and clean user interface
- Interactive task management using JavaScript

## Technologies Used

- **HTML5** – For the structure of the application
- **CSS3** – For styling and responsive design
- **JavaScript** – For functionality and DOM manipulation
- **Local Storage** – For saving tasks in the browser

## How It Works

Users can enter a task and add it to the Todo List. Each task can then be marked as completed, edited, or deleted. The application uses browser Local Storage to save the tasks, allowing them to remain available even after the page is refreshed or the browser is reopened.
